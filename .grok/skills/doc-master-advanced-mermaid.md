# Documentation Master – Advanced Mermaid Generator

## Description
Create beautiful, advanced Mermaid diagrams for all architecture docs.

## Required Diagrams (per package)
- Dependency graph (subgraph style)
- Build & compilation flow
- Data flow between core classes (EngineV3, unified pipeline, lookup, pods)
- State machine for key features (hierarchy, note refs)

## Style Rules
- Use subgraphs, styling, and comments for clarity
- Always include "Current Status" and "Roadmap" sections
- Update tracker after every diagram
